## 部署

GitHub Pages 从 `main` 分支的 `docs/` 目录发布。网站为云端静态托管，访问者不依赖开发电脑开机。

后续更新时，用新的完整生产构建替换 `docs/` 内的网站文件并提交，保留 `.nojekyll`。分享链接和站内生成的卡片二维码会使用当前 HTTPS 域名与目录。
