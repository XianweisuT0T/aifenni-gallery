# 爱分你 · 微型画廊与作品来信

[进入微型画廊](https://xianweisut0t.github.io/aifenni-gallery/)

让人停下来，看见一幅画、记住一位画者，也把一句心意带给下一位。

## 手机图片与浏览性能（v17）

首页主画按画面比例和屏幕选择预览，邻画用缩略图；作品普通页、个人展厅、共创与周边也按显示尺寸加载。82张公开作品/对照素材提供640与960长边预览，srcset标注实际宽度，不把长边误写为宽度。点开完整大图、查看展开图局部和生成分享卡仍读取原清晰文件；原图、题名、署名和74个作品入口不变。

页头原品牌图使用28/56/84px版本，替代用887×1774的大图显示一个小标识。首页首次打开不创建完整画廊；第一次进入画廊才挂载，之后保留组件、观看模式与三排位置。流动展墙缓存行宽信息，窗口尺寸变化时重测；展墙移出屏幕或页面不可见时暂停计算，再可见后接续，不改变用户选择的静止模式。

固定月亮样本的首页三图从989,956B降到124,906B，约减少87.4%；首次首页图片元素从257个降到21个。数据来自同一组作品的浏览器自动化，弱网/CPU模拟不代表真实手机或每次网络速度。GitHub Pages线路与设备仍会影响实际等待。

预览图随源码交付，无须访问第三方图片服务。需要重建时在项目目录执行 `node scripts/build-art-previews.mjs`；原始公开展示图保留在public/art。源码不包含私人管理表或原始附件压缩包。

## 扫码、看画与单幅接力

- 实物作品吊牌使用对应作品链接，月亮示例直达 `#/work/moon`；老师总览码进入首页。首页随机遇见作品，两个入口职责不同。
- 首页改为一主两辅的三幅错落展陈，撤掉包围作品的巨型外框。每幅衬纸随实际长宽比变化，原图不裁切、不补画；邻画保留题名、署名，点击或键盘操作可交换主次，主展签和展厅入口跟随当前主画。设计展开图与分镜仍有完整图和四象限局部查看。
- 初次主画仍从全部74件中随机遇见，另两幅优先来自其他画者，并兼顾原作、二创与不同画面比例。点击邻画只交换这三件作品的位置；“换一组看看”另遇见一组且不立即重复当前主画。它只是首页展陈，不是已取消的三幅选画或组合分享功能。
- 手机竖幅主画与右侧两幅邻画上下错落；横幅、方幅和设计展开图则让主画占据上方整行，两幅邻画在下方左右错落，不把宽画挤成小图。中等宽度平板先完整展陈再呈现主题。题名、署名可读可点；主画廊入口始终在个人展厅上方。
- 实物作品页把短介绍放在画旁边，优先认识画者、再分享和继续逛画廊。从画廊弹窗进入的完整作品页保留来源，返回时恢复展墙位置和页面位置。
- “只看作品”可以收起展签，画作题名与画者仍保留；重新展开恢复操作，也支持作品页 `?view=art`。画信中的安静看画使用同画大图窗口，关闭后仍回到同一封已揭晓的画信。
- 通过分享链接收到作品时，随画留言贴近画作与题名展示；接收者可以选另一幅画回应这份心意。
- 分享先看完整卡片：桌面大预览与设置并列，手机留言/版式按需展开；一键写话打开并聚焦最多60字的自定义留言。保存与复制持续在底部可达。
- 复制受限时可展开并选中链接手动复制。分享卡生成失败可以重试，当前作品、留言和版式会保留。
- 共创页先看两幅作品与同等清楚的署名，再选择看画线索。漫境组有人工核对、可开关的小鱼与大鹅标记，其他三组不借用其标记或推定对应区域。

## 当前作品与入口

74幅独立作品包括60幅原作修复图、14幅二创修复图，来自29位创作者。
完整画廊提供“流动展墙 / 静静看画”、静态目录和按画名查找。停止/恢复、关闭弹窗、离开后返回，均保留观看位置；手机初访默认手动横向浏览，系统减弱动态时保持静态。静态展墙支持键盘浏览74个真实作品链接。
打开看画、分享或关于弹窗期间，展墙临时停止自动移动并保留每排位置。关窗后只有原先选择流动时才接续；静止模式与系统减弱动态不会被关窗唤醒。
个人展厅提供依据实际作品和创作资料的介绍。
顶部“共创”看4组已核实原作与二创对照；画廊“二创作品”分类浏览14件独立二创。导航状态与分类网址保持同步。
主题以孤独症公益项目提供的艺术素材为起点，通过欣赏、署名、留言和分享支持创作者被看见、人与人建立联系。不会根据画面推定个人诊断或声称治疗效果。
新版沿用品牌绿 #254B43，展墙暖白 #F7F5EF、衬纸 #FFFEFA、正文 #2B322E、辅助字 #626E63，陶土 #A5523B 只在画信/分享作少量点缀。放大署名和关键正文，避免装饰遮盖画作。
画廊页面引用同一背景变量；手机首页主题说明在常规/窄屏分别为15/14px，自然换行。
手机左上保留原爱分你标识，右上保留周边、关于和月亮信封徽标；第二行主导航提供进入画廊、展厅和共创。
既有额外组合选画和首页翻面不再使用，旧组合链接回到完整画廊。

## 围绕同一幅画的日常周边

`#/merch` 提供“自己选一幅”与“拆一封画信”。`#/merch?work=moon` 预选作品；`#/merch?mode=blind` 直达拆信。
艺术版画、明信片和帆布袋使用真实完整画作预览。直接选购仅生成本次体验清单；既有版画/明信片认购演示仍兼容旧链接。
“拆一封画信”为免费试拆，十二幅公开作品等概率出现。封套改变后续相处方式：给今天留一句话、向想到的人问候、或安静看画与保存票根；不自动填写留言，也不改变随机概率。
封套呈现为暖白纸质的画廊来信，保留清楚的收件主题、品牌徽标邮票、装饰邮戳与可拆封带。三种封套以小色签区分，缩略预览与大信封一致；撕口和下方主按钮调用同一次开封逻辑。
动画可跳过并响应减弱动态设置；主动再次体验才重新抽取，切换栏目不会更换已揭晓的作品。
两种体验均不收手机号或地址，不发生真实支付或发货，不宣称稀有奖品或募款实绩。

## 托管与源码

GitHub Pages从main分支的/docs目录自动部署，访问不依赖开发电脑开机。
完整源码和同步PPT、PDF与测试材料通过课程交付包提供。源码使用React/Vite，执行 `npm ci`、`npm test`、`npm run build`，再将dist内容更新至docs并保留docs/.nojekyll。
生产配置 `VITE_BASE_PATH=./`、`VITE_PUBLIC_SITE_URL=auto`，分享链接使用实际HTTPS站点与目录。

79个固定入口地址保持：首页、74幅作品、4组共创对照。实物吊牌应指向对应作品，教师总览码指向首页。

## 资料与验证边界

题名、署名与修复展示图按课程材料核对。两件二创无正式题名，明确标为未命名；不猜测其余二创的原作关系。
不发布完整Excel、原始大ZIP及出生、年龄、学号、操作人等私人管理字段。
认购没有真实扣款、支付、订单或作品交付后台。
开发自动检查和浏览器尺寸核验不替代真人试用。历史旧版研究与本轮测试材料分开保存；本轮3位目标用户的自然扫码、提示后任务和实证修改结果仍待实际执行与填写。

## 弹窗临停回归

`scripts/browser-modal-wall.cjs` 检查三排真实横向位移：流动时会走、看画/分享弹窗期间停在同处、关窗只恢复原流动模式，并覆盖静止、系统减弱动态及键盘关闭。脚本从当前浏览器网址读取站点地址，不绑定开发端口或本机文件路径。
启动 `npm run dev` 后，可用 Playwright CLI 打开开发网址，再执行 `run-code --filename scripts/browser-modal-wall.cjs`。这是浏览器自动化，不能替代真实手机和真人试用。

参考 W3C SC 2.2.2 的暂停/停止机制与 SC 1.4.3 的文字对比度目标；交付记录仅对选定色对和具体交互核验，不等于完整 WCAG 认证。后续“分享我看到的这一处”仍为待验证的拓展构想。
