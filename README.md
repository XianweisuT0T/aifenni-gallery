# 爱分你 · 三幅口袋小展

[进入微型画廊](https://xianweisut0t.github.io/aifenni-gallery/)

从74幅作品中挑三幅，组成自己的口袋小展，给它取名，再把邀请卡或链接分享给下一位。

## 当前体验

- 74幅独立作品：60幅原作修复图、14幅二创修复图；29位创作者分别拥有自己的展厅。
- 首页随机遇见作品，突出进入画廊入口；画廊点击看画后保持运动，尊重系统减少动态效果设置。
- 从画廊或画者展厅加入三幅不同作品，进度可见，支持移出、更换和调整顺序。第四幅不会挤走已选作品。
- 给三幅小展取名，最多14个Unicode字符；邀请卡保留完整画面、题名、署名与原作/二创标识。
- 小展链接和卡片二维码复现同一顺序的三幅作品与展名；接收者可继续策划自己的小展。
- 单幅分享仍支持推荐语、60字自定义留言、展览票根及画信；艺术版画与艺术明信片提供对应设计预览。
- 保留4组资料明确的原作/共创对照，其他二创独立展出，不推测配对。
- 手机左上保留爱分你原标识，月亮信封图标位于右上“关于”旁；暖白纸面、清晰展签与轻木框。

## 托管与更新

GitHub Pages由 `main` 分支的 `/docs` 目录自动部署，访问者不依赖开发电脑开机。
部署产物在 `docs`，完整源码与同步PPT通过课程交付包提供。本仓库不含依赖、私人管理表或原始大压缩包。

源码使用React/Vite，执行 `npm ci`、`npm test`、`npm run build` 后将dist内容更新至docs，并保留docs/.nojekyll。
生产配置 `VITE_BASE_PATH=./`、`VITE_PUBLIC_SITE_URL=auto` 使站内链接使用实际HTTPS站点与目录。

作品入口为 `#/work/作品ID`，共创对照为 `#/cocreation/对照ID`；三幅小展使用 `#/exhibit?works=ID1,ID2,ID3&title=展名`（实际链接经过URL编码）。
小展无需账户和数据库。未完成选画草稿只在当前页面内存，完成后保留小展链接即可复现，不声称账户云收藏。

老师总入口二维码指向网站首页；实物吊牌应指向对应作品。月亮示例吊牌使用 `#/work/moon`，不要把所有作品码统一换成首页。
同一网址未变，原有有效二维码继续打开最新页面。

## 素材与验证

图像、题名与署名来自课程材料核对，素材为修复展示图。两幅二创缺少正式题名，明确标为未命名。
不公开完整Excel、原始ZIP、出生、年龄、学号或操作人等私人管理字段。

自动化测试覆盖作品归档、选择上限、URL顺序与标题、无效入口、图片完整比例、分享与认购隔离。
开发浏览器检查与真实手机/微信试用分开记录，不将浏览器模拟写成课堂用户研究。
用户在较早版本曾确认同一网址的手机浏览器与微信入口正常；这不代表新增小展和相册保存已完成手机实机验证。

认购为课堂交互演示，无真实扣款、支付、订单或作品交付后台。
