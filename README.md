# 爱分你 · 微型画廊与画作周边

[进入微型画廊](https://xianweisut0t.github.io/aifenni-gallery/)

从一幅画继续看，也把一句心意带给下一位。

## 扫码、看画与单幅接力

- 实物作品吊牌使用对应作品链接，月亮示例直达 `#/work/moon`；老师总览码进入首页。首页随机遇见作品，两个入口职责不同。
- 实际作品页先展示完整画面，题名与画者署名紧随其后，主画廊入口位于个人展厅入口上方。
- 通过分享链接收到作品时，随画留言贴近画作与题名展示；接收者可以选另一幅画回应这份心意。
- 分享先看画，再写推荐语或最多60字自定义留言。编辑有直达入口，弹窗底部保留下载卡片和复制链接操作。
- 复制受限时可展开并选中链接手动复制。分享卡生成失败可以重试，当前作品、留言和版式会保留。
- 共创对照在两幅画前先呈现真实观察线索，帮助寻找原作保留的元素和二创的变化。

## 当前作品与入口

74幅独立作品包括60幅原作修复图、14幅二创修复图，来自29位创作者。
完整画廊提供持续运动展墙、静态目录和按画名查找；个人展厅提供依据实际作品和创作资料的介绍。
顶部“共创”看4组已核实原作与二创对照；画廊“二创作品”分类浏览14件独立二创。导航状态与分类网址保持同步。
主题以孤独症公益项目提供的艺术素材为起点，通过欣赏、署名、留言和分享支持创作者被看见、人与人建立联系。不会根据画面推定个人诊断或声称治疗效果。
新版沿用米白、深绿与温金的品牌配色，以更有层次的展墙构图、大标题与装帧细节突出真实完整原画。
手机左上保留原爱分你标识，右上保留周边、关于和月亮信封徽标；第二行主导航提供进入画廊、展厅和共创。
既有额外组合选画和首页翻面不再使用，旧组合链接回到完整画廊。

## 围绕同一幅画的日常周边

`#/merch` 提供“自己选一幅”与“拆一封画信”。`#/merch?work=moon` 预选作品；`#/merch?mode=blind` 直达拆信。
艺术版画、明信片和帆布袋使用真实完整画作预览。直接选购仅生成本次体验清单；既有版画/明信片认购演示仍兼容旧链接。
盲盒为免费试拆，十二幅公开作品等概率出现。选择纸封套后拆封，揭晓署名和作品；可以走进画者展厅、带画留言或选择周边。
动画可跳过并响应减弱动态设置；主动再次体验才重新抽取，切换栏目不会更换已揭晓的作品。
两种体验均不收手机号或地址，不发生真实支付或发货，不宣称稀有奖品或募款实绩。

## 托管与源码

GitHub Pages从main分支的/docs目录自动部署，访问不依赖开发电脑开机。
完整源码和同步PPT、PDF与测试材料通过课程交付包提供。源码使用React/Vite，执行 `npm ci`、`npm test`、`npm run build`，再将dist内容更新至docs并保留docs/.nojekyll。
生产配置 `VITE_BASE_PATH=./`、`VITE_PUBLIC_SITE_URL=auto`，分享链接使用实际HTTPS站点与目录。

79个固定入口地址保持：首页、74幅作品、4组共创对照。实物吊牌应指向对应作品，教师总览码指向首页。

## 资料与验证边界

题名、署名与修复展示图按课程材料核对。两件二创无正式题名，明确标为未命名；不猜测其余二创的原作关系。
不发布完整Excel、原始大ZIP及出生、年龄、学号、操作人等私人管理字段。
认购没有真实扣款、支付、订单或作品交付后台。
开发自动检查和浏览器尺寸核验不替代真人试用。历史旧版研究与本轮测试材料分开保存；本轮3位目标用户的自然扫码、提示后任务和实证修改结果仍待实际执行与填写。
