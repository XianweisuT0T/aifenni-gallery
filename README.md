# 爱分你 · 装进口袋的微型画廊

[进入微型画廊](https://xianweisut0t.github.io/aifenni-gallery/)

60幅原作修复图、14幅二创，74幅作品、29位创作者，另有4组有来源依据的原作与共创对照。

首页随机遇见一幅画；画者拥有独立展厅。画廊在悬停、点击和打开看画卡片时持续运动；系统减少动态设置仍受尊重。版画A4与明信片100×150分别预览，明信片可翻面。

分享先看画再写文字，支持60字自定义留言、展览票根与画信两种版式。作品专属链接仍直达对应作品，自定义留言作为普通文本随链接传递。

部署：GitHub Pages从main分支的docs/发布；云端静态托管，不依赖开发电脑开机。更新时替换完整构建并保留.nojekyll。

本轮37项自动测试及手机/桌面尺寸开发浏览器检查通过。新界面的真人双人接力和课堂用户研究仍待执行；此前同一入口的手机浏览器、微信扫码可达性已由用户确认。

认购仍为课堂交互演示，不发生真实扣款或发货；完整Excel、原始压缩包和私人管理字段未发布。
