# 爱分你 · 微型画廊

[进入微型画廊](https://xianweisut0t.github.io/aifenni-gallery/)

一进来先看到画作。手机端以完整画廊为主入口，个人展厅为次入口；从作品走近创作者，也能看原作与二创之间的回应。

## 三种入口，分别做什么

- **完整画廊 / 找作品**：74幅作品的持续运动速览和静态目录。按画作名称查找，再按全部、原作、二创作品筛选；不再重复设置按画者下拉筛选。
- **画者展厅**：29位创作者各自的作品空间，加入引用真实作品和明确创作资料的介绍，继续看本人署名的作品。
- **顶部共创**：4组资料明确的原作与二创配对。它展示两位创作者的作品如何相互回应；画廊里的“二创作品”则筛选14件独立二创。

板块用编号、留白、底色和边界分开。导航只提示一个当前入口，作品类型与网址同步，切换、刷新和返回保留一致状态。

## 当前体验

74幅独立作品包括60幅原作修复图、14幅二创修复图，来自29位创作者。
手机主画廊按钮位于个人展厅入口上方；背景保留柔和展墙光影和细线装饰。
点击作品后画廊持续运动，尊重系统的减少动态效果偏好。
单幅分享先画后文，支持推荐语、最多60字自定义留言、展览票根和画信版式。
艺术版画与艺术明信片有对应产品预览，明信片可查看正反面。
左上保留爱分你原标识，右上“关于”旁保留月亮信封图标。

## 托管与更新

GitHub Pages从main分支的/docs目录自动部署，访问者不依赖开发电脑开机。
仓库保存部署产物，完整源码和同步PPT/PDF通过课程交付包提供。
源码采用React/Vite，执行npm ci、npm test、npm run build后，将dist内容更新至docs并保留docs/.nojekyll。
VITE_BASE_PATH=./、VITE_PUBLIC_SITE_URL=auto使分享链接使用实际HTTPS域名和目录。

固定79个入口地址未变：老师总入口指向首页；实物吊牌使用对应作品码，月亮示例直达#/work/moon。
旧版额外组合选画功能与首页翻面已移除，旧组合链接回到完整画廊。

## 素材与验证

作品题名、署名和图像按课程资料核对，素材为修复展示图。两件二创缺正式题名，明确标为未命名。
创作介绍引用实际作品、明确创作说明及4组已核实的配对，不编造画者年龄、生平、诊断或心理特征。
不发布完整Excel、原始ZIP、出生、年龄、学号、操作人等私人管理字段。
自动测试、开发浏览器验证与真人研究分开记录。旧版本同网址手机/微信可达反馈不代表新界面已完成真人试用。
认购为课堂交互演示，无真实扣款、支付、订单或交付后台。
