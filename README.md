# 爱分你 · 微型画廊

[进入微型画廊](https://xianweisut0t.github.io/aifenni-gallery/)

一进来先看到画作，从作品和署名走进对应画者的展厅，再继续看与分享。

## 当前体验

- 74 幅独立作品：60 幅原作修复图、14 幅二创修复图，来自 29 位创作者。
- 首页先呈现完整作品、题名和署名，点击画作直接看清画面，画者展厅入口明确可见。
- 完整画廊以展墙、卡纸与展签组织作品，提供持续运动速览、静态目录、类型分类和搜索。
- 每位创作者各有自己的展厅，只展示实际署名属于本人的作品。
- 保留 4 组资料明确的原作/二创对照，其他二创独立展示，不猜测关系。
- 单幅分享先看画再选文，支持预设推荐语、最多 60 字自定义留言、展览票根与画信版式。
- 艺术版画和艺术明信片有对应产品设计，明信片可查看正反面。
- 手机左上保留爱分你原标识，右上“关于”旁保留月亮信封图标。

本轮移除额外组合选画任务及首页翻面动作。旧版组合链接回到完整画廊。画廊点击作品后保持运动，并尊重系统的减少动态效果设置。

## 托管与更新

GitHub Pages 从 `main` 分支的 `/docs` 目录自动部署。访问者无需开发电脑开机。
仓库保存可部署网页，完整源码、同步 PPT 与 PDF 通过课程交付包提供。
源码采用 React/Vite，执行 `npm ci`、`npm test`、`npm run build` 后，将 dist 内容更新至 docs，并保留 docs/.nojekyll。
生产配置 `VITE_BASE_PATH=./`、`VITE_PUBLIC_SITE_URL=auto`，分享链接使用实际 HTTPS 站点及目录。

作品入口为 `#/work/作品ID`，画者展厅为 `#/artist/画者ID`，共创对照为 `#/cocreation/对照ID`。
教师总入口二维码指向首页。物理吊牌应使用对应作品码，月亮示例直达 `#/work/moon`。
固定入口网址未变，现有二维码继续打开最新页面。

## 素材与验证

图像、题名与署名按课程资料核对。素材为修复展示图，两幅缺正式题名的二创明确标为未命名。
不公开完整 Excel、原始 ZIP、出生、年龄、学号或操作人等私人管理字段。
自动测试、开发浏览器检查与真人研究分别记录。旧版本同一网址已有用户手机浏览器/微信入口可达确认，新界面和相册保存仍需实际设备试用。
认购为课堂交互演示，无真实扣款、支付、订单或交付后台。
