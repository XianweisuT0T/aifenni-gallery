# 爱分你 · 装进口袋的微型画廊

[进入微型画廊](https://xianweisut0t.github.io/aifenni-gallery/)

展出60幅原作修复图、14幅二创，共74幅作品、29位创作者，另有4组有资料依据的原作与共创对照。

## 本轮界面细修

手机左上保留原爱分你标识，右上在关于旁显示月亮信封图标；导航适配320/375/430宽度。暖白底去除全页横纹，减轻木框与纸张阴影，展签与操作文字更清晰，按钮层次统一；首页画纸轻微倾斜，增加翻面提示与短淡入。

保留随机初遇、独立画者展厅、持续流动画廊、版画及明信片预览、自定义60字留言、票根与画信分享卡。系统减少动态设置仍受尊重。

## 部署与验证

GitHub Pages从main分支的docs/目录发布，访问不依赖开发电脑开机。教师总入口二维码进入随机首页，实物吊牌使用对应作品专属码（月亮示例为#/work/moon）。

37项现有自动测试和生产构建通过，320/375/430/1366尺寸开发浏览器验证通过。历史同一入口曾经用户手机及微信确认可达；本轮新视觉的真人试用仍待完成，不将开发检查当成用户研究。

认购仍为课堂演示，无真实扣款或发货；未发布完整Excel、原始压缩包及私人管理字段。
